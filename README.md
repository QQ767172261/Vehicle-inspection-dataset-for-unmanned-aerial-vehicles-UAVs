### 公众号摘要

**标题：无人机航拍车辆检测数据集｜万张航拍图，24w+车辆标注**
正文摘要：
本数据集采用DJI Mini3 Pro无人机，在50m、70m、90m高度采集俯视航拍图像，共10000张1920×1080实拍图片，车辆标注实例超24万个。YOLO标注格式，单类别car，覆盖黑、蓝、棕、灰、绿、红、银、白、黄多种颜色车辆。场景包含露天停车场、城市道路交叉口，存在车辆密集排布、树荫局部遮挡等真实工况，适合无人机低空车流量统计、空地目标检测、智慧交通、科研模型训练。

**封面短摘要**
DJI Mini3多高度航拍车辆数据集，10000张图，24w+车辆实例，YOLO标注，适用于低空航拍车辆检测与交通分析。

### 应用价值

1. 低空无人机交通巡检，自动统计车流量、识别停车场空余车位；
2. 俯视小目标车辆检测算法训练，解决航拍密集车辆、遮挡检测难点；
3. 城市低空安防、园区车辆普查、智慧交通项目模型验证；
4. 高校/科研机构计算机视觉、遥感目标检测方向实验使用。
